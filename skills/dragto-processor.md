# DragToWhatever processor skills

Two supported ways to add processors. Prefer JSON for new sites.

| Path | Skill | When |
|------|-------|------|
| Declarative JSON | [dragto-processor-json.md](dragto-processor-json.md) | New sites; Load JSON in overlay; no rebuild for file iteration |
| TypeScript built-in | [dragto-processor-ts.md](dragto-processor-ts.md) | Complex cases or shipped built-ins; rebuild required |

Overview also in the [README](../README.md#custom-processors).
